# Speak-Ez Sessions

Documentation for the event stack: the contract, the tickets, the gallery, and the door. Specs are written next to the code and copied into this site when it is built. Guides and disclaimers live here.

The public event site is [permissionless.money/alpha/sezs](https://permissionless.money/alpha/sezs/). This is pilot software, and it has not been audited. Read the [disclaimers](/disclaimers) before you buy a ticket or send funds.

## How this site is built

A script pulls `SPEC.md` and `BENCHMARK.md` from the contract crate, the circuit crate, the gallery folder, and the FROST admin folder. The result is a static tree. Edit those source files, not the generated copies under Specs.
