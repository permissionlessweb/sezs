## How this site is built

A script reads the ZIP-style preambles in `docs/specs/` and writes the specs index, each specification page, and the sidebar. Adjacent in-repo notes (gallery, admin, proof benchmarks) are copied from their paths in this repository. Edit those sources, not the generated copies under Specs.
