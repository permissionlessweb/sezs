# Install a wallet

How these wallets are used on the event site is also in [Wallets](/guides/general/wallets).

Install Zafu first if you will pay in ZEC or sign in with Zafu. A ZIP-321 wallet such as Zashi or Ywallet is optional, for paying a ticket invoice outside Zafu. Keplr is not a sign-in option on this site.

## 1. Zafu first

[Zafu](https://zafu.pro) is the first wallet to install if you will pay in ZEC or log in with Zafu. Use it to receive, store, and send shielded ZEC from a wallet you control, and to sign a site-scoped ZID for this origin.

Install [Zafu](https://zafu.pro) from the official site, [zafu.pro](https://zafu.pro). Do not download a wallet from a search-ad, a forwarded file, or a look-alike site. Write the recovery phrase on paper and keep it offline. Nobody from the event, and no page in this software, should ever ask you to type that phrase into a website.

After it is installed, create or restore a wallet and let it sync. You will need a receive address when you [buy ZEC](/guides/general/purchasing-zec) and when you pay a ticket invoice.

## 2. Optional: a ZIP-321 wallet

If you already pay shielded ZEC from [Zashi](https://electriccoin.co/zashi/) or Ywallet, you can use that wallet to open the ticket invoice. You still sign in on the event site with Zafu or a passkey.

## After install

- ZEC you will spend should sit in [Zafu](https://zafu.pro) (or another shielded wallet you control), not on an exchange.
- Do not paste ticket secrets or recovery phrases into chat, email, or the event backend.
- If a page asks you to reveal a ticket secret to a server, stop and treat that as a bug. The [ticketing spec](/specs/ticketing) forbids the backend from learning the secret.
